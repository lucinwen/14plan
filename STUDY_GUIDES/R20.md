# R20｜BEHAVIOR-1K：什么叫真正的具身交互任务？（Day03/08）

**入口**：[Stanford BEHAVIOR-1K官方站](https://behavior.stanford.edu/)。你要学习的是“任务初态→目标状态→对象可交互性→可复现评测”，不要求两周内复现1000个任务。

## 建议阅读顺序（约40–50min）
1. 首页理解为什么把日常人类活动转成机器人任务；不要只看场景渲染。
2. 查看一个 Activity/Task 示例：有哪些对象、初始状态和目标谓词？
3. 追溯 BDDL 或任务定义：`initial` 和 `goal` 如何判定，而不是让观察者看视频主观判断成功。
4. 看任务可执行条件：相同空间布局为何可能因为物体状态、能力限制而失败？
5. 读评测说明：episode reset、场景/seed、成功率以及不同平台的可比边界。

## 举例：与SceneWeaver的关联
用户说“打开柜子，找到杯子，放到桌上”。房间连通和对象显示正确只是一部分：
- 柜门应有 `open` 状态、物品 `inside(cup,cabinet)`。
- 机器人需可到达/抓取/打开，且观测可能被门遮挡。
- 成功条件应该是 `on(cup,table)` 等状态满足；不能靠图像漂亮来评估。

## 你的练习
写 `goal / initial / object_states / robot_capabilities / observations / success_checker / failure_reasons` 的任务模板；固定机器人和任务，在3个不同布局重复测试，记录因几何/状态/动作造成的失败。没有实际物理rollout，就只报告**受限任务检查**。

**验收**：解释语义对象和真实可交互对象差别；为什么任务完成率比“场景像不像房子”更能体现具身价值。
