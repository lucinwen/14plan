# R08｜robomimic：理解模仿学习算法，而不是直接复制训练脚本（Day07选读）

**入口**：[robomimic 官方 Algorithms](https://robomimic.github.io/docs/introduction/implemented_algorithms.html)。这是对照材料，不要在两周内把所有算法/依赖全部安装跑通。

## 阅读顺序与问题（约30–40分钟）
1. 找 **Behavior Cloning (BC)**：输入专家 `observation`，监督预测 `action`，离线损失低不意味着 rollout 高成功率。
2. 找序列策略（如 BC-RNN / Transformer，依文档当前可用模块）：过去观测为什么重要？时间窗口长短如何影响动作连续性？
3. 对照 Diffusion Policy（若工具文档/版本提供相关实现，缺则跳到 [原论文](P01.md)）：它如何表示多峰动作序列，与直接均方误差回归有什么区别？
4. 看 Evaluation/rollout 的定义：专家数据训练集成绩与从随机初始状态开始的实际执行成功率不同。

## 给简历做一次方法对照
选场景“打开门后拿物体”：
- BC 训练数据每一帧应包含相机、机器人关节/末端姿态、动作、时间戳吗？缺一项会怎样？
- 假设训练只见左开门，测试出现右开门：是状态估计、数据分布还是策略造成失败？如何公平验证？
- 它解决的是**学习执行策略**，而你 SceneWeaver 主要在**生成、组织并验证环境/任务**；两者可连接但不能相互替代。

## 小练习：数据结构草案
写一个示例 `episode_id, observations, actions, timestamps, initial_state, success` 的 JSON Schema 草图，不采集真人数据；为每项写单位、坐标、是否可观测，列至少三种数据泄漏方式（相同实例/场景/资产同时进入训练测试）。

**验收**：闭卷解释 BC covariate shift、离线loss与在线执行、为什么动作策略无法证明生成环境合法。明白这些就停止，不必训练网络。
