# 资源学习指南｜不要打开一门几十小时课程从头刷

> **这是 `DAILY/day-XX.md` 的子教程目录。** 每天计划负责时间/主题；每份资源教程负责告诉你“打开哪一节、跳过哪一节、怎么练、什么算学会”。**22份课程/工具 R01–R22 + 9份论文/研究 P01–P09**，都有独立文件。链接分P经过课程目录核对的会注明；未逐帧播放过的视频不声称已完全核实字幕。

## 你的 Belean 比邻项目案例
- [**Belean 全系统学习指南**](../PROJECT_GUIDES/BELEAN.md)：Day13配套；空间选择、双方ready、旧revision拒绝、WebXR手动对齐、WebRTC/WebSocket分层、逐次触碰许可及技术/商业验证边界。
- Day10的3DGS和角色表征课程也借 Belean 的研究路线说明“视觉资产”和“可驱动/可接触人物”为什么不能等价。

## Day01 现在就这样操作
1. 打开 [Day01总计划](../DAILY/day-01.md) 做45分钟闭卷前测。
2. 打开 [**R01 Modern Robotics精确分P**](R01.md)：**必看P4/P9/P10/P11/P12/P16**；视频约23min + 画图手算与闭卷，累计约65min。**不要看完43集**。
3. 打开 [R16 MIT课程选取指导](R16.md)：今天优先看官方几何位姿估计讲义图与概念约30–40min；**不要看完80分钟的P5**。
4. 回 Day01 完成其余项目反例、minilab测试和口头追问。完成后只需记录“我能解释/不会解释的具体问题”，不要盲目增加新课。

### 每份子教程的固定使用法
**开始前**：读“为什么学/本日必看”→**观看中**：遇到示例就暂停回答→**观看后**：先独立写/画一个具体案例→**验收**：不看资源回答问题→**退出规则**：通过就停，未通过只回看指定小节。课程长短与掌握程度不能直接画等号。
