# R19｜Isaac Lab：机器人训练任务到底需要哪些字段？（Day06–08）

**官方**：[Isaac Lab教程](https://docs.nvidia.com/learning/physical-ai/getting-started-with-isaac-lab/latest/isaac-lab-basics/01-the-isaac-platform.html) / [Isaac Sim](https://docs.isaacsim.omniverse.nvidia.com/latest/core_api_tutorials/index.html)。主要研究 **任务契约**，不先安装仿真平台；Isaac Lab的软件版本和具体类名以官方文档为准。

## 逐字段学（建议60min）
- **Scene**：环境实体、机器人模型、物理碰撞、关节、静态/动态物体；是否支持可复位？
- **Observations**：哪一个传感器或状态进入策略？真值、噪声、时间戳以及部分可观测性？
- **Actions**：策略输出什么？位置/速度/力矩/末端目标，如何映射控制器，单位与频率如何定？
- **Rewards**：中间奖励和最终成功是否一致？能否刷取奖励而不完成任务？
- **Terminations/Resets**：超时、越界、失败、完成怎样触发，下一个episode如何回到可复现初始条件？
- **Randomization**：如何调整布局、物体、传感噪声而不破坏训练/评测划分？

## 用一张任务表实践
自己填 “送物到目标房间”：
| 字段 | 假设/输入 | 需要补的技术 |
|---|---|---|
| robot | 宽度、关节、控制接口 | URDF或articulation、控制器 |
| scene | 生成空间/门洞/碰撞 | 几何、物理、资产、随机化 |
| obs | RGB-D、关节状态 | 传感和同步 |
| action | 前进或末端移动 | 控制/安全 |
| reset | 门/物体/机器人回初始 | 物理状态复位 |
| success | 物品成功抵达 | 任务谓词/轨迹检查 |

## 三个陷阱
- USD导入成功 ≠ 训练可用。
- 物理仿真能运行 ≠ 策略训练或物理成功率已验证。
- 随机化范围更广 ≠ 已证明跨具身泛化。

**验收**：闭卷给出1份自洽 observation/action/reward/reset/termination 合同，画出策略与环境一步交互时间线，并指出三种失败来源。
