# P03｜OpenVLA 源码与论文：理解离散动作 token 路线（Day07选读）

**入口**：[OpenVLA官方项目仓库](https://github.com/openvla/openvla)。先看README的Architecture、Model、Inference/Action部分，不需要两周内跑满模型训练。

## 50分钟的正确读法
1. **10min**：找一条推理输入：图片、自然语言指令、可能的机器人条件信息；明确数据格式和前处理假设。
2. **10min**：研究动作如何表示/离散化/生成，以及输出如何解码成实际机器人动作；与π0连续动作生成的区别。
3. **10min**：读训练来源、机器人平台和适用范围；不把论文中演示平台上的成功当作所有机器人通用。
4. **10min**：读微调/部署依赖；记录模型、计算、观测标准化以及控制接口的工程门槛。
5. **10min**：填比较表：OpenVLA / π0 / BC / Rule Planner 分别在哪里承担责任。

## 面试最关键的问题
如果 OpenVLA 输出一个7维动作向量，但你的机器人需要不同关节数量/坐标系，会发生什么？要做 action adapter、机器人能力边界与安全控制，并通过实验验证，不是把数字直接转发给电机。

**验收**：解释动作 token化的利弊、训练与推理条件及不同平台部署的问题，且不声称已亲自训练/部署该模型。
