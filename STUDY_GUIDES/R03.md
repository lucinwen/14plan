# R03｜微软 Z3：从约束表达学到冲突诊断（Day02，Day03复用）

**入口**：[Z3 Guide](https://microsoft.github.io/z3guide/) · [Z3Py官方教程](https://github.com/microsoft/z3guide/blob/main/website/docs-programming/02%20-%20Z3%20Python/01%20-%20Introduction.md) · [Programming Z3](https://z3prover.github.io/papers/programmingz3.html)。这门资源是文档而非视频，不必找一个“2小时B站合集”来凑时长。

## 先建立4层概念
1. **变量/理论**：`Int`, `Real`, `Bool`，算术关系由 SMT 理论支持；Z3 不会自动知道现实世界碰撞。
2. **约束**：`And/Or/Not/Implies`，将“房间不重叠”表示为**沿至少一个轴分离**；绝不能误写成每个轴都分离。
3. **求解结果**：`sat` 说明形式化公式有模型；`unsat` 说明已编码约束一起不相容；`unknown` 不等于无解。
4. **调试**：`push/pop` 增量试验，`assert_and_track` / assumptions标记冲突，`unsat_core` 不保证唯一或最小。

## 该读哪部分（约90分钟内容学习）
- **20min**：Z3Py入门：`Solver()`, `check()`, `model()`，亲自换一个约束看返回值。
- **25min**：布尔连接词和数值变量，写 `Or(xa+wa<=xb, xb+wb<=xa, ya+ha<=yb, yb+hb<=ya)`。
- **20min**：`push/pop` 看加入门宽限制前后模型如何变化。
- **25min**：标记约束 + `unsat_core`；用两条相互矛盾的不等式找一组冲突证据。

## 必做的三个案例（在自己的学习目录，不碰腾讯内部工程）
- **SAT**：两间 2×2 房放入宽4高3边界，允许相邻。
- **UNSAT**：两间 2×2 房要求放入3×3盒内且不能相交。解释可用横/纵两种分离；此例在2D确实放不下。
- **诊断**：独立写出 `door_width>=0.8` 和 `door_width<=0.5`，跟踪约束后反查为何无解。

示例：`python -m minilab.z3_demo`（可选先安装 `pip install -r minilab/requirements.txt`）。再自己修改房间宽度或楼层约束，保留输入、输出、求解器版本和自己解释的冲突原因。

## 最后要讲得出口
**“SMT sat ⇒ 公式满足”**，并不推出“门接面合法 ⇒ 机器人能走 ⇒ 机械臂能抓 ⇒ 任务成功”。独立验证输入结构、几何接触、动作状态和物理执行。

自测：①为什么非重叠是 Or？②硬约束与优化目标区别？③UNSAT core 能否当成唯一修复方案？④超时怎么报告？能连续答对三轮才算通过。
