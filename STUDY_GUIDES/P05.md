# P05｜MIT Robotic Manipulation 教材精读法：科研视角（Day03/06/08）

**官方**：[MIT在线教材](https://manipulation.mit.edu/)，具体B站讲次见[R16](R16.md)，本教程只解决**怎样阅读/对比论文式研究框架**，不重复R16视频选P。

## 每天选一个不同研究问题
- Day03：Task-and-Motion Planning；写清 **离散动作目标 / 连续空间约束 / 失败反馈**。
- Day06：几何感知与仿真；写清**观测/真实状态/物理模型**各来自哪里。
- Day08：对照任务环境生成系统；写清“生成一个场景”与“机器人策略在这里执行成功”之间的接口。

## 1小时一轮精读
1. 5min 看目标案例：机器人“抓取杯子并放到桌上”。
2. 15min 按教材定义拆输入/输出/假设，比如相机已知位姿或物体几何是否已知。
3. 15min 临摹关键图/模型——闭卷用自己的语言重画。
4. 15min 设两个反例：遮挡/任务状态错误 vs 机械臂IK碰撞失败。
5. 10min 与简历项目联系：哪些组件你参与过、哪些是拟研究；不因看懂教材就声称独立开发控制器。

**验收**：能够在白板把语言目标→符号计划→连续运动→状态反馈画完整，并指出两个假设不成立时哪个模块负责报告。
