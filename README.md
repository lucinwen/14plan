## 每天怎么学（10h，休息另计）

1. **2h 课程**：带着问题看 B 站指定选集，不刷完整合集。
2. **3h 原理**：画流程、写输入输出、推导关键定义与约束。
3. **3h 验证**：用简历项目做最小实验、对照案例或系统设计；Codex 可辅助执行。
4. **1h 复述**：关掉资料，用自己的话讲为什么、怎么做、哪里失败。
5. **1h 面试**：让 AI 连续追问；把不懂的问题写入错题簿。

每天只用回答五个问题：**它解决什么？输入输出？为什么选它？怎么做/测？在哪些条件下失败？**
