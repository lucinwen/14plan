## 强化练习｜六个可重复的SAT/UNSAT场景

本地创建`D02_six_solvers.md`，每组先写变量/范围/公式/预测，再记录运行。
设两房均是2m×2m轴对齐矩形、建筑高3m、宽W，非重叠必须满足`(Ax+2≤Bx)∨(Bx+2≤Ax)∨(Ay+2≤By)∨(By+2≤Ay)`。这是**至少一个方向分离**，不可以写四个方向全成立。

| 输入 | 模型内预期 |
|---|---|
| W=4 | SAT |
| W=5 | SAT |
| W=6 | SAT |
| W=3 | UNSAT |
| W=2 | UNSAT |
| `door_width≥0.8`并且`door_width≤0.5` | UNSAT |

可选先安装`pip install -r minilab/requirements.txt`，然后`python -m minilab.z3_demo`及`--width 3`。以`assert_and_track`给矛盾门宽加标签，观察`unsat_core`；它不是唯一或者一定最小的“错误约束集合”。改一个参数，比较输出和自己的预测。**若依赖卡住，保留纸面推导并写未运行**。

常见障碍：W3意外SAT→检查边界约束或有无非重叠Or；W4意外UNSAT→排查附加条件；UNKNOWN或超时→不能当作无解，先缩小案例、记录预算与条件。
