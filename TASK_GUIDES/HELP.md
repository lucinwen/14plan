# 学不会、看不懂、运行失败时怎么办？｜14天学习救援手册

> 本页不是再加一门课，而是保证你在任何一天遇到卡点都有明确下一步。每天10小时**有效学习**；课程跳过不等于掌握，硬件没有安装也不应凭空报告实机成功。

## 先花3分钟判断是哪种卡点
| 当前症状 | 通常不是因为你不努力 | 立刻执行的动作 | 成功退出标准 |
|---|---|---|---|
| 视频一集看完仍不懂 | 名词间的依赖关系不清 | 在[知识地图](../KNOWLEDGE_MAP.md)定位它属哪一层；打开对应R/P子教程只看指定章节 | 能用“输入—处理—输出”一句话解释 |
| 公式看不懂 | 坐标/角度/变量意义没写明 | 列“符号、单位、约定、已知、要求”；先代入最简单的整数角度 | 能手算一个基线与一个失败例 |
| Python/Z3运行错误 | 依赖版本或输入格式问题 | 复制精确命令、错误全文、Python版本、预期与实际；跑最小样例 | 同一条件再次运行结果可解释 |
| 没有GPU或机器人 | 实验条件不具备 | 改做任务契约/手算/mini lab二维受限反例；明确“未跑物理执行” | 有明确输入、规则、预期、未验证边界 |
| 论文读不下去 | 还没看到研究问题与方法边界 | 先只读摘要、方法图、实验标题，再画3个模块 | 能说研究贡献和至少一个限制 |
| 面试问三句就卡住 | 在背术语而非理解因果 | 从首次原话找“定义/推导/接口/验证/真实性”哪个环节缺失 | 同题能不看稿再答两次 |
| 某天学习超时 | 课程内容超过预期 | 保留核心产物，先砍选修；D+1复习不能取消 | 保留有证据的进度，未做标“未做” |

## 一套不会导致“AI给答案、你还是不懂”的求助协议

先自己写下面的五行（不用写完整论文）：

~~~text
【Day和阶段】例如 Day02 第3阶段：二维矩形不重叠
【原题与我的变量定义】xA,yA,wA,hA...
【我现在的想法】我认为需要每个轴都分离
【具体卡点/失败输出】公式得到UNSAT，或minilab打印了blocked_geometry
【我期望AI怎么帮助】先指出哪条假设错了，只给1条提示，不要直接交完整答案
~~~

给AI的建议Prompt：

> 你是我的具身智能学习教练。请只利用这道题提供的前提、我原本的回答和对应的TASK_GUIDES，先定位**第一个错误假设**。不要立刻给标准答案；先问我一题让我自行纠正，接着给一个最小反例。必要时展示不超过8行关键公式/伪代码。我回答后再给下一步。将“源码执行过”“我只设计过”“历史工作做过”三种证据明确区分。最后让我闭卷复述两分钟。

## 特别常见的5个实际困境

### 1. Modern Robotics听完P16还是不会矩阵
不要从P1刷完43集；回[R01](../STUDY_GUIDES/R01.md)，先用**旋转单位阵和平移(2,0,0)**推点(1,2,0)变世界点(3,2,0)，再加旋转90°。每次写 `T_target_source` 的方向。能反算回来即止。

### 2. Z3已经装好了，但结果和预期不一样
先看[R03](../STUDY_GUIDES/R03.md)的变量/边界/析取，确保程序真使用了你修改后的约束。`sat`只表示编码公式有模型；`unsat core`不一定唯一最小。把反例缩成2个矩形/2条约束，绝不直接删除用户硬要求。

### 3. 具身仿真环境装不起来
不要耗尽一天配置Isaac。优先[R19](../STUDY_GUIDES/R19.md)的 observation/action/reward/reset 合同和[MiniLab](../minilab/README.md)的受限规则验证；“没有实际运行物理”不是失败，但如果声称已实测才是错误。

### 4. 数字人/雷达术语能说但说不出因果
选一个实际失败：旧语音被打断却继续播、胸部运动干扰呼吸估计，按`输入信号→处理→判断→错误条件→恢复`写出链路；需要什么传感、如何评估，不允许拿漂亮演示当精度数据。

### 5. 实习细节无法对外展示
可以用**自制、公开原理的替代示例**讲约束求解、异步任务、API或系统设计。机密代码/未公开指标、企业UI截图不上传Public，也不为获得录取虚构个人职责。核查责任优先于背术语。

## 什么时候该停止学习一门课？
不是听完所有视频，而是：①独立定义输入输出；②画出主要因果；③至少一个成功样例和一个失败反例；④区分未验证范围；⑤闭卷回答两轮为什么。如果还不足，就针对错处复看资源教程指定小节，不拓展新视频。
